# Field & Veld

An offline farm record book for Windows. It keeps records of your fields, crops,
plantings, spraying and weeding, scouting reports, harvests, sales, costs and
crew — all on your own computer.

- **No internet needed** — not to install it, not to use it
- **No account to sign up for, nothing to pay**
- **Your records stay on your computer** — encrypted, nothing is sent anywhere

---

## Download

**Get the latest build from the
[Releases page](https://github.com/tatendachitima/field-and-veld/releases).**

Pick the most recent release and download
`Field-Veld-0.9.0-x64-setup.exe`. The file is about 213 MB — that's normal.
Everything it needs is packed inside, so it installs the same on a farm with no
signal as it does in town.

> **Windows will warn you the first time.** You'll see a blue
> *"Windows protected your PC"* box. Click **More info → Run anyway**. This is
> expected for any program that hasn't been through Microsoft's paid signing
> process. Full details in [INSTALL.md](INSTALL.md).

## Quick start

1. Download `Field-Veld-0.9.0-x64-setup.exe` from the Releases page.
2. Double-click it. When Windows warns you, click **More info → Run anyway**.
3. Open **Field & Veld** from the Start menu and set a password.

Complete instructions — backing up, the worker portal, voice messages — are in
**[INSTALL.md](INSTALL.md)**.

## What it does

- **Fields & crops** — your blocks of land and what you grow (ready-made Zimbabwean crop templates)
- **Plantings** — a crop, in a field, on a date (the record everything else hangs off)
- **Activities, scouting, harvests** — day-to-day field work
- **Sales, costs, inventory** — money in and out
- **Labour** — your crew, with PINs for the worker portal
- **Reports** — profit & loss, budgets, meal planning
- **Worker portal** — phones on the same wifi log scouting and harvests with picture-based forms
